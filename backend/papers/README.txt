EXAM PAPER FILES
================

Put each unit's exam paper PDF in this folder, named exactly as the unit id:

    UCI101.pdf   (Fundamentals of Information Technology - all programmes)
    ESE110.pdf   (Introduction to Special Needs Education - all programmes)
    EPY110.pdf   (Introduction to Educational Psychology - all programmes)

A unit with no matching file shows "Paper not yet available" on the dashboard.
